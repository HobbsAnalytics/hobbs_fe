## Governance note: `drawing_register` is not synced

`mfg_mc_se_sa.bluerridge_gold_pm.drawing_register` is deliberately **not** synced to Lakebase. It carries a Unity Catalog row filter (by discipline, via `bluerridge_agents.discipline_access`). Row filters and column masks are not propagated to synced tables, so a Postgres copy would hand every connected role all rows and bypass the filter. The app reads `drawing_register` through the SQL warehouse, where the filter is enforced.
