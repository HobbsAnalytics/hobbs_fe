title: "Exit access travel distance"
source: "IBC"
is_paraphrase: true
related_flaw_type: egress_width_under_code
---
The distance an occupant must walk to reach an exit is limited, and the limit depends on the use and on whether the building is sprinklered. A reviewer measures the longest path from any point in a space to the nearest exit and compares it to the limit.
