title: "Employers must have an energy control program"
source: "OSHA 29 CFR 1910"
is_paraphrase: true
related_flaw_type: missing_loto_tag
---
The employer must establish a program with energy control procedures, employee training and periodic inspections. The program makes sure equipment is isolated and made inoperative before servicing. A reviewer looks for a reference to the site lockout program on the drawing or the equipment list.
