title: "Outside contractors and host employer coordination"
source: "OSHA 29 CFR 1910"
is_paraphrase: true
related_flaw_type: missing_loto_tag

When contractors work on equipment at a host site, the host and the contractor must tell each other about their lockout procedures so that every worker is protected. A reviewer checks that the project safety plan covers contractors' use of the site lockout program.
