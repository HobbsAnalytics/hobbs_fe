title: "Egress width per occupant for doors, ramps and other components"
source: "IBC"
is_paraphrase: true
related_flaw_type: egress_width_under_code
---
Doors, ramps, corridors and other egress components use a smaller per-occupant width factor than stairs. The factor, multiplied by the occupant load, gives the minimum capacity of the component. A reviewer compares the occupant load served by each door or passage with the clear width shown on the drawing.
