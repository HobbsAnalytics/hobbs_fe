title: "Assembly of bolted flanged joints"
source: "ASME B31.3"
is_paraphrase: true
related_flaw_type: flange_rating_mismatch
---
Bolted flange joints must be assembled so the gasket is evenly compressed, using tightening methods and bolt loads suited to the gasket and flange class. A correct flange class still leaks if the joint is badly made. A reviewer checks that the bolting and gasket on the drawing agree with the flange class and that torque or tightening requirements are noted.
