title: "Relief discharge piping"
source: "ASME B31.3"
is_paraphrase: true
related_flaw_type: missing_pressure_relief_notation
---
The outlet of a relief device must be piped to a safe location such as a flare, a closed vent header or a safe point outdoors. The discharge line must not add back-pressure that stops the device working. A reviewer checks that a discharge destination is shown for each relief device.
