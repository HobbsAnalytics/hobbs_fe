title: "Door hardware must open without a key"
source: "IBC"
is_paraphrase: true
related_flaw_type: egress_width_under_code
---
Egress doors must be openable from the inside without a key, special knowledge or more than one operation. Locks that need a key to exit are not permitted in the path of egress. A reviewer checks the door hardware schedule for each exit door.
