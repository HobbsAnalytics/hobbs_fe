is_paraphrase: true
related_flaw_type: flange_rating_mismatch

Each flange material belongs to a material group, and each group has its own table of allowable pressure at each temperature. Carbon steel, low-alloy steel and stainless steel flanges of the same class can therefore carry different pressures. A reviewer confirms the material called out on the drawing and uses the table for that group when checking the flange class.
