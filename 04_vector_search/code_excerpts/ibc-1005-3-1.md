title: "Stairway egress width per occupant"
source: "IBC"
is_paraphrase: true
related_flaw_type: egress_width_under_code
---
Stairways serving the egress path are sized with a per-occupant width factor, with a minimum clear width regardless of the load. A reviewer multiplies the occupant load served by the stair by the factor and compares it to the width drawn, checking the clear width between handrails.
