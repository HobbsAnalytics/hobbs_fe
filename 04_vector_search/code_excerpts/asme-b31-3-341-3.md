Each weld examination method comes with acceptance criteria that define which indications are acceptable, such as limits on cracks, incomplete fusion or porosity. A weld that fails the criteria must be repaired or replaced and re-examined. A reviewer checks that the drawing or the project specification names the acceptance standard used for each weld.
