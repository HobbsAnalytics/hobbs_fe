title: "Minimum width of the means of egress"
source: "IBC"
is_paraphrase: true
related_flaw_type: egress_width_under_code
---
The width of each egress component, such as a door, corridor, stair or exit passage, must be large enough to carry the occupant load that uses it, and it can never be smaller than the stated minimum clear width. The required width is found by multiplying the number of occupants by a per-person factor, then comparing the result to the minimum. A reviewer reads the occupant load and the drawn clear width of each egress path, and flags any exit door or passage that is too narrow for the egress requirement.
