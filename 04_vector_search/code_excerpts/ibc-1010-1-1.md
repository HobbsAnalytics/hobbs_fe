title: "Minimum clear width of an exit door"
source: "IBC"
is_paraphrase: true
related_flaw_type: egress_width_under_code
---
An egress door must provide a minimum clear opening width measured with the door open, which is less than the nominal size of the door leaf because of the frame and hardware. A door that looks wide enough on a plan may fail on clear width. A reviewer checks the clear opening and not just the nominal door size.
