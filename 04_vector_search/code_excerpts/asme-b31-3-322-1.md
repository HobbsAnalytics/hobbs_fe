title: "Relief device set pressure"
source: "ASME B31.3"
is_paraphrase: true
related_flaw_type: missing_pressure_relief_notation
---
A relief device must open at or below the design pressure of the protected system, allowing for the permitted accumulation above set pressure. A set pressure above the design pressure of the weakest component defeats the protection. A reviewer compares the set pressure noted on the drawing with the design pressure of the lowest-rated component.
