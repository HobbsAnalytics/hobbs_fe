title: "Means of egress illumination and emergency power"
source: "IBC"
is_paraphrase: true
related_flaw_type: egress_width_under_code
---
The egress path must be lit whenever the building is occupied, and the lighting must keep working on emergency power if normal power fails. A reviewer checks that emergency lighting is shown along egress paths and that a backup power source is identified.
